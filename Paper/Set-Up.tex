Fig.\,\ref{fig:set-up} shows a simplified schematic version of the \emph{Bruker IFS 66 v/s} fourier spectrometer. 
The source (1) emmits light in the near-
infrared range ($1500\,\text{cm}^{-1} - 15000\,\text{cm}^{-1}$) which is then reflected on the beam splitter (3). 
The Beamsplitter, static mirror (4) 
and movable mirror (5) can be seen as a michelson interferometer which is used to create a interference pattern.
During the measurement, the movable mirror is moved with constant speed.
The light is then focused via another mirror (6) on the sample (7). In this case, transmission is shown.
For reflection measurements an additional module is used which is not shown in the figure. Mirror (8) then 
focuses the light onto the detector (9). The signal is then digitalized.
Numbers (10) to (13) show the beampath of a laser which is used to determine the position of the movable mirror.
